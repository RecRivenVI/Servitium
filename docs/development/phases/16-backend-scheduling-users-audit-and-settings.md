# 阶段 16：计划任务、用户、审计与设置

## 1. 阶段目的

补齐控制平面的治理能力与节点的本地自治能力：计划任务（Agent 权威存储与调度）、用户与授权的完整流程、双日志流的完整事件覆盖、系统设置全分组、仪表盘布局。

## 2. 需求编号

`REQ-SCH-001` … `REQ-SCH-050`、`REQ-USR-001` … `REQ-USR-062`、`REQ-SEC-080`、`REQ-I18N-001` … `REQ-I18N-004`（服务端部分）。

## 3. 前置条件

* 阶段 15 完成条件全部满足。

## 4. 范围

* 计划任务：定义、触发、动作链、重叠策略、执行历史、本地自治与对账；
* 用户管理与实例授权的完整端点（阶段 12 已实现基础，本阶段补齐级联清理与批量）；
* 操作日志与安全审计的完整事件覆盖与查询导出；
* 系统设置全分组（基础、外观、安全、身份、关于）与资源上传；
* 仪表盘布局按用户存储、保存、重置、升级补齐；
* 诊断导出；
* 数据保留期清理作业；
* 数据库备份。

## 5. 非目标

* 不实现前端界面。

## 7. 需要实现的类型或模块

### 7.1 计划任务（Agent 权威）

| 组件 | 职责 |
| --- | --- |
| `LocalScheduler` | 从本地数据库加载任务；为每个启用的任务建立触发器；进程重启后恢复 |
| `TriggerCalculator` | 计算下次触发时间（三种触发方式） |
| `ActionExecutor` | 按序执行动作链；实现重叠策略；记录逐动作结果 |
| `RunHistory` | 保存每任务最近 100 条执行记录 |

**本地自治**：控制平面离线时调度照常运行；执行历史写入本地并通过 Outbox 在重连后上报。

**编辑流程**：控制平面接收编辑请求 → 下发 `UpsertSchedule` → Agent 校验并持久化 → 返回结果 → 控制平面更新镜像。节点离线时编辑返回 `node-offline`。

**对账**：重连时 Agent 上报全部任务定义与版本；控制平面以 Agent 为准更新镜像，差异记入操作日志。

### 7.2 用户与授权

补齐：批量禁用与删除、级联清理（实例删除登记时移除授权）、Windows SID 绑定端点、重置他人 TOTP、吊销他人全部会话、用户统计。

### 7.3 双日志流

**操作日志**必须覆盖的动作（不完全列举，实现时以「所有改变系统状态的操作」为准）：

节点注册与移除、凭据轮换与吊销、Java 登记与删除、实例创建与修改与删除登记与删除目录、实例生命周期动作、发送命令、EULA 同意、文件增删改与传输、配置写入与备份恢复、模组启停与删除与上传、计划任务增删改与手工执行、用户增删改与禁用、授权变更、设置变更、布局保存与重置、诊断导出、数据库备份、HMCL 的全部写操作（阶段 17）。

**安全审计**必须覆盖：`REQ-USR-032` 列出的全部事件。

两者共用脱敏中间层。

### 7.4 系统设置

补齐外观与身份分组；实现资源上传（Logo、背景、提供方图标）与 SVG 消毒；实现「立即生效 / 需要重启」的标注元数据；实现 OIDC 发现文档测试与 TLS 证书校验端点。

### 7.5 仪表盘布局

按用户存储；读取时若无自定义布局返回默认布局；版本升级时把新增页面追加到用户布局；重置删除该用户的布局记录。

### 7.6 维护作业

| 作业 | 说明 |
| --- | --- |
| 保留期清理 | 按 `data-and-storage.md` 第 7 节的保留期清理各类数据；每次清理写操作日志；清理审计日志的作业本身写审计 |
| 数据库备份 | 每日自动备份（可关闭）+ 手工触发；使用 SQLite 在线备份 API |
| 上传会话清理 | 清理超期的分片暂存 |
| 诊断导出 | 生成脱敏诊断包 |

## 11. 关键算法

| 算法 | 说明 |
| --- | --- |
| 下次触发时间 | 间隔：`上次触发 + 间隔`（首次为 `启用时刻 + 间隔`）；日历：按节点本地时区，从当前时刻起找下一个匹配「星期集合 × 时刻」的时间点；指定：固定时间点，过期则不触发 |
| 重叠策略 | `跳过`：前次未结束则丢弃本次并记录；`排队`：入队，队列上限 3，超出丢弃最旧并记录；`并发`：直接开始新的执行 |
| 动作链执行 | 顺序执行；`延时` 使用可取消的等待；`发送命令` 复用终端输入路径；生命周期动作复用阶段 14 的服务；任一失败按配置中止或继续 |
| 执行次数 | 每次触发（含排队执行）后递减；减到 0 时任务自动停用（不删除） |
| 对账（计划任务） | Agent 上报 `(任务标识, 版本号, 定义哈希)` 列表；控制平面按 Agent 为准更新；孤儿镜像被删除并记录 |
| SVG 消毒 | 解析 XML → 移除 `<script>`、事件属性（`on*`）、`<foreignObject>`、外部引用（`href` 指向非 `#` 的目标）、`<use>` 的外部引用 → 重新序列化；解析失败即拒绝 |
| 诊断导出脱敏 | 遍历配置与日志，按秘密类型的键名与值模式替换为固定占位符；导出前用已知秘密值做一次自检 |
| CSV 导出 | 流式生成；字段按 RFC 4180 转义；BOM 可选（默认带 UTF-8 BOM 以便 Excel 正确识别） |

## 12. Windows 平台事项

* 计划任务使用 Agent 进程内的定时器，**不使用** Windows 任务计划程序（避免额外权限与外部依赖）；
* 节点本地时区用于日历触发；系统时区变更时重新计算全部触发器；
* 系统休眠与唤醒后重新计算触发器（避免定时器漂移）；
* SQLite 在线备份需注意文件锁与 WAL。

## 13. 安全要求

* `REQ-SEC-080` 审计不可修改：本阶段扩大审计覆盖后仍需通过 `SEC-350`、`SEC-351`；
* 资源上传的 SVG 消毒（`SEC-121`）；
* 诊断导出脱敏（`SEC-330`，此时秘密类型已基本齐全）；
* 设置变更的审计必须记录变更前后值且敏感值脱敏；
* 保留期清理不得删除未超期的审计条目；审计保留期不得配置为低于 90 天。

6. 系统设置全分组可用；资源上传与 SVG 消毒生效；
7. 布局按用户存储、重置、升级补齐生效；

## 20. 禁止提前进入下一阶段的条件

* 计划任务未实现本地自治（依赖控制平面在线）；
* 审计覆盖不全或可被修改；
* 诊断导出泄露秘密；
* 设置变更未写审计或未记录前后值。
