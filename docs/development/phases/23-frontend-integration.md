# 阶段 23：双端集成

## 1. 阶段目的

确认 Web 与 Desktop 在信息架构、字段、动作、状态、权限与文案上完全一致；完成跨端的端到端、性能、无障碍与本地化验证；准备用户验收所需的环境与材料。

## 2. 需求编号

`REQ-DSK-050`（双端一致性）、`REQ-I18N-002`、`REQ-I18N-004`，以及全部界面需求的最终验收。

## 3. 前置条件

* 阶段 22 完成条件全部满足。

## 4. 范围

* 双端一致性全量比对；
* 跨端端到端场景；
* 性能验证；
* 无障碍验证；
* 本地化完备性验证；
* 前端自主检查表（`docs/testing/frontend-acceptance.md`）；
* 用户验收材料准备。

## 5. 非目标

* 不新增功能；
* 不做用户验收（阶段 24）；
* 不进入交付。

## 6. 需要创建的项目或目录

无新增项目。可能在 `tests/Servitium.EndToEndTests` 中新增跨端场景。

## 7. 需要实现的类型或模块

* 一致性比对报告生成器：把两端采集的清单与契约比对后输出结构化报告（缺失 / 多余 / 顺序不符 / 文案键不同）；
* 用户验收环境启动脚本：`eng/StartAcceptanceEnvironment.ps1`（拉起 Development Server + Agent + Vite + Debug Desktop，使用独立测试数据库与测试目录，输出访问地址、账号、PID 与日志位置）。

## 8. 数据模型

无变更。

## 9. API 或事件

无新增。

## 10. 实施顺序

1. 运行双端一致性全量比对，修复全部差异；
2. 编写并运行跨端端到端场景；
3. 性能验证（两端）；
4. 无障碍验证（两端）；
5. 本地化完备性验证（两端 + 服务端错误码覆盖）；
6. 逐条完成 `docs/testing/frontend-acceptance.md` 的检查表；
7. 编写 `eng/StartAcceptanceEnvironment.ps1`；
8. 准备用户验收材料（见第 16 节）；
9. 连续运行 3 次完整验证，确认无随机失败；
10. 运行 `eng/Validate.ps1 -Profile FrontendGate` 全量。

## 11. 关键算法

| 算法 | 说明 |
| --- | --- |
| 一致性比对 | 三方比对：契约 × Web 采集 × Desktop 采集。对每个页面输出四类差异：契约有而某端无（缺失）、某端有而契约无（多余）、区块顺序不符、同一元素在两端使用了不同的文案键 |
| 采集标记 | Web 使用 `data-servitium-page` / `-section` / `-field` / `-action` / `-state`；Desktop 使用同名的 `AutomationId` 约定 |
| 平台专属排除 | 契约中标注 `platformOnly: web|desktop` 的条目不参与跨端比对，但仍参与与契约的比对 |

## 12. Windows 平台事项

Desktop 的 UI 自动化需要交互式桌面会话。若测试在无交互会话中运行，必须报告并请求用户协助，不得跳过。

## 13. 安全要求

* 一致性比对不得因「补齐差异」而在某端暴露超出该角色权限的字段或动作；比对结果必须区分「实现缺失」与「权限正确隐藏」；
* 用户验收环境使用独立测试数据库与测试目录，**不污染正式数据**；
* 验收环境的测试账号密码在验收结束后失效（环境销毁即失效）。

## 15. 集成测试

### 15.1 跨端端到端

| 编号 | 场景 |
| --- | --- |
| `X2E-001` | 在 Web 创建实例，在 Desktop 看到并可操作 |
| `X2E-002` | 在 Desktop 启动实例，Web 的状态在 2 秒内更新 |
| `X2E-003` | 两端同时打开同一实例的终端，输出一致，观察者数为 2 |
| `X2E-004` | 在 Web 撤销授权，Desktop 的终端在 2 秒内被关闭并提示 |
| `X2E-005` | 在 Desktop 上传文件，Web 的文件列表刷新后可见 |
| `X2E-006` | 在 Web 发布 HMCL Release，Desktop 收到系统通知并可深链接跳转 |
| `X2E-007` | 在 Desktop 修改系统设置，Web 刷新后生效 |
| `X2E-008` | 长操作在一端发起，两端都能看到进度并在任一端取消 |
| `X2E-009` | 语言在一端切换为个人语言，不影响另一端的其他用户 |
| `X2E-010` | 控制平面重启后，两端自动重连并补发事件 |

* 性能指标未达标；

* 用户验收材料不完整。
