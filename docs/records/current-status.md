## 4. 进行中的工作

当前已形成服务端压缩包导入、任意绝对路径登记、Prism 原生 ZIP 后端安全预览/转换与 HMCL 自动更新分发四条合成可测纵向链路。PB-021 已修复 Kestrel 30 MB 默认请求体上限，31 MiB 以上合成数据已贯通三条上传链路。PB-022 至 PB-038 已由正式协议、Desktop、纵向端点、权限、生命周期和未打包 WinUI 资源回归关闭；PB-039 因用户真实启动截图暴露 Desktop 响应式布局阻断而重新进入进行中；PB-040 的 Desktop 事件流 CSRF 握手与可选 GUID 查询问题已修复，但不改变 PB-039 的 UI 阻断状态。最终完整验证覆盖率为整体 70.85%，Domain 与 Application 均不低于 85%。

2026-08-04 当前代码包含 OIDC、本机换票、ConPTY、RCON、文件/配置/模组、计划、治理、完整 HMCL 生命周期、生成协议 Client 和 30 页 Desktop。OpenAPI 含 145 个路径、181 个操作及准确的请求/成功/错误响应；两种 Desktop 资源各 776 个键。此处仅说明代码与自动测试事实，阶段 18、22、23、24 均未通过。隔离 Server PID 90100 仍监听 `http://127.0.0.1:9100`，Server 与 Desktop 测试数据位于 `artifacts/test-runs/interactive-d7aa986cc884407e98e1aab0f15af486/`；本轮启动的合成 Server `9201` 与 Desktop UIA 进程均已停止。PB-040 修复后，8 个顶层导航页面完成 UIA 检查，但不等于 30 页逐页验证。

依据 2026-08-03 的最新用户决定，四项真实样本测试统一延后到阶段 12–17 后端生产代码、共享客户端与正式 WinUI 3 Desktop 代码完成之后。现有单窗口测试工作台仅作为 Desktop 实现起点；允许继续正式 Desktop 开发，但不启动 Web、交付、安装包、CI 或发布，也不据此宣称阶段 18、23、24 通过。
