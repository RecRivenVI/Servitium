# 后端验收清单

阶段 18 使用本清单。每一项必须**实际运行**并留下证据（命令、输出摘要、产物路径），记入 `docs/testing/acceptance-matrix.md`。

不得以静态审查代替运行。不得跳过。缺少权限或环境时按权限阻塞流程请求用户协助。
