调查依据见 `../research/survey-mcsmanager_layout.md`；控件与视觉规范见 `../design/principle-user_interface.md`。

## 3. 页面规格

每页按统一结构描述：**目的 / 权限 / 入口 / 区块顺序 / 字段 / 主要动作 / 次要动作 / 批量动作 / 状态 / 错误 / 空态 / 破坏性操作 / 平台差异 / 依据与需求**。

### PG-001 首次初始化

* **目的**：创建唯一 Owner 并完成最小可用配置。
* **权限**：匿名；仅回环请求或持一次性初始化令牌。
* **入口**：未初始化时任何路由强制跳转。
* **区块顺序**
  1. 产品标识与版本；
  2. 前置条件说明（数据目录、监听地址、服务账户）；
  3. Owner 账户表单；
  4. 提交。
* **字段**：用户名（必填，1–64）、密码（必填，≥12，带强度指示）、确认密码、界面语言（默认按系统区域）。
* **主要动作**：完成初始化。
* **状态**：提交中禁用表单。
* **错误**：`already-initialized` → 引导至登录；`weak-password` → 就地提示；来源受限 → 说明必须在服务器本机完成。
* **平台差异**：Desktop 在连接到未初始化的本机 Server 时进入同一页面。
* **需求**：REQ-IDN-001、REQ-IDN-002、REQ-IDN-003。

---

### PG-002 登录

* **目的**：本地账户或外部身份登录。
* **权限**：匿名。
* **区块顺序**
  1. 产品标识与自定义登录页文本（配置了才显示）；
  2. 用户名与密码表单；
  3. 登录按钮；
  4. 分隔线（配置了 OIDC 才显示）；
  5. 外部身份登录按钮（含提供方图标与名称）。
* **字段**：用户名、密码。
* **主要动作**：登录。
* **次要动作**：使用 <提供方> 登录。
* **状态**：提交中；自动跳转倒计时（可取消）。
* **错误**：凭据无效（统一文案，不区分用户存在性）；账号已禁用；触发限流（展示 `Retry-After` 换算后的时间）。
* **破坏性操作**：无。
* **特别要求**：即使启用「自动跳转到身份提供方」，本地登录表单也必须以可展开区域保留（`REQ-IDN-053`）。
* **平台差异**：Desktop 在本机换票可用时跳过此页；换票失败时进入此页并在顶部说明原因。
* **需求**：REQ-IDN-010、REQ-IDN-013、REQ-IDN-040、REQ-IDN-053、REQ-DSK-003。

---

### PG-003 两步验证

* **区块顺序**：说明 → 6 位验证码输入 → 提交 → 「使用恢复码」切换。
* **主要动作**：验证。
* **次要动作**：使用恢复码、返回登录。
* **错误**：验证码无效；尝试次数过多。
* **需求**：REQ-IDN-021。

### PG-010 实例列表

* **目的**：跨节点浏览与批量管理实例。
* **权限**：Owner/Administrator。
* **区块顺序**
  1. 页头（左：标题 + 实例总数；中：过滤条；右：节点选择器 + 「新建实例」）；
  2. 工具栏（左：批量模式切换 / 刷新；中：已选数量；右：分页）；
  3. 标签云；
  4. 主体（单节点：卡片网格；全部节点：分组表格）。
* **过滤条**：状态下拉（全部 / 运行中 / 已停止 / 启动中 / 停止中 / 忙碌 / 已崩溃 / 不可达）、名称搜索（输入节流 400 ms）。
* **节点选择器**：「全部节点」 + 各节点（离线节点标注但可选）+ 分隔 + 「管理节点」。
* **卡片字段**：名称、状态徽章、标签、Java 运行时、监听端口、在线玩家、内存、CPU、上次启动。
* **卡片动作**：启动 / 停止 / 重启 / 强制终止（按状态显示）｜ 分隔 ｜ 编辑标签、打开控制台、更多（同步整合内容、实例设置、删除登记）。
* **表格列（全部节点视图）**：名称、状态、节点、Java、端口、玩家、上次启动、操作。
* **批量动作**：启动、停止、重启、强制终止、删除登记。**无批量删除目录。**
* **状态**：加载（骨架卡片）、空、节点离线（分组标注不可达且动作禁用）。
* **空态**：「该节点下还没有实例」+「新建实例」。
* **破坏性操作**：强制终止（确认，说明可能损坏存档）、删除登记（确认，展示工作目录路径并说明目录将被保留）。
* **平台差异**：Web 卡片栅格 `xxl=4/xl=6/lg=8/md=12/sm=24`；Desktop 使用等价的自适应网格。
* **需求**：REQ-INS-001 … REQ-INS-004、REQ-INS-030、REQ-INS-014。

### PG-011 我的实例

* **目的**：`User` 角色的主页。
* **权限**：User。
* **区块顺序**：① 四个统计块（全部 / 运行中 / 已停止 / 异常）② 授权实例卡片网格。
* **空态**：「管理员尚未向你授权任何实例」。
* **需求**：REQ-USR-025。

### PG-012 实例控制台

* **目的**：查看输出、发送命令、执行生命周期操作、进入各管理入口。
* **权限**：User + 该实例授权。
* **区块顺序**
  1. 页头（左：实例名 + 状态徽章 + 节点名 + 观察者数；右：生命周期动作组 + 溢出菜单）；
  2. 终端卡片（宽 12，高「大」）；
  3. 基础信息卡片（宽 4）；
  4. 管理入口卡片（宽 8）。
* **页头主要动作**：启动 / 停止 / 重启 / 强制终止（按状态）。
* **页头次要动作**（溢出菜单）：同步整合内容、导出会话日志、查看日志文件、实例设置。
* **终端卡片**
  * 主体：输出区（等宽字体、ANSI 渲染可开关、自动滚动可暂停、支持搜索）；
  * 底部：命令输入框 + 发送按钮 + 快捷命令按钮组；
  * 右上：清屏、复制全部、导出、字号调整、打开独立终端。
* **基础信息字段**：状态、节点、工作目录（可复制）、Java 运行时、启动方式摘要、监听端口、在线玩家、上次启动、自动启动、自动重启。
* **管理入口**（顺序固定）：配置文件、文件管理、模组与插件、计划任务、Java 运行时、RCON、服务器查询、终端设置、自动启停、整合内容关联、实例设置。
* **状态**：实例不可达（节点离线）时终端区显示说明并禁用输入；实例停止时终端显示最后缓冲并禁用输入。
* **错误**：无权限 → 说明页；实例不存在 → 说明页 + 返回列表。
* **破坏性操作**：强制终止。
* **平台差异**：Desktop 的「打开独立终端」创建独立窗口；Web 打开新标签页。
* **需求**：REQ-TRM-001 … REQ-TRM-033、REQ-INS-040 … REQ-INS-043。

### PG-013 文件管理

* **目的**：管理实例工作目录内的文件。
* **权限**：User + 授权，且受全局「普通用户文件管理」开关约束。
* **区块顺序**
  1. 页头（左：标题 + 实例名；中：文件名搜索；右：从 URL 下载 / 上传 / 粘贴或刷新 / 新建或批量操作）；
  2. 传输任务区（有任务时出现）；
  3. 目录标签栏；
  4. 面包屑（可切换为路径输入）；
  5. 文件表格。
* **表格列**：选择框、名称（图标 + 名称，目录可点击进入）、类型、大小、最后修改、操作。
* **行动作**：编辑（文本）、下载、重命名、复制、剪切、压缩、解压（归档）、删除。
* **批量动作**：下载（打包）、复制、剪切、压缩、删除。
* **对话框**
  * 新建 / 重命名：单输入框 + 合法性校验；
  * 压缩：归档名 + 条目名编码；
  * 解压：目标（当前目录 / 新建目录 + 目录名）+ 条目名编码；
  * 从 URL 下载：URL + 目标文件名 + 覆盖策略；
  * 覆盖确认：列出冲突项与处理方式。
* **状态**：加载（骨架行）、空目录、任务进行中（进度行）、配额已满（禁用新任务并说明）。
* **错误**：`path-escapes-root`、`path-name-invalid`、`file-locked`、`disk-space-insufficient`、`file-too-large` 各有专门文案。
* **空态**：「该目录为空」+「上传文件」。
* **破坏性操作**：删除（确认，展示条目数与总大小）。
* **明确不提供**：盘符切换、跨卷浏览、权限（rwx）编辑。
* **平台差异**：Desktop 支持从资源管理器拖放上传；Web 支持目录选择上传。
* **需求**：REQ-FIL-001 … REQ-FIL-064。

### PG-014 配置文件总览

* **区块顺序**：页头（标题 + 刷新）→ 配置文件列表。
* **列表项字段**：文件名、格式标签、最后修改时间、冲突标记（如有）、说明。
* **主要动作**：编辑。
* **次要动作**：在文件管理中打开、查看备份。
* **空态**：「未找到可识别的配置文件」+「打开文件管理」。
* **需求**：REQ-CFG-001、REQ-CFG-013。

---

### PG-015 配置文件编辑

* **区块顺序**：页头（左：返回；右：保存 / 还原 / 切换到原始文本 / 备份）→ 结构化表单（按字段分组）或原始文本编辑器。
* **表单分组**（`server.properties`）：网络、游戏玩法、世界、性能、安全、其他。
* **主要动作**：保存（`Ctrl+S`）。
* **次要动作**：还原未保存修改、切换视图、查看与恢复备份。
* **状态**：加载、保存中、有未保存修改（页头标记 + 离开确认）。
* **错误**：`config-parse-failed` → 在对应行列就地提示；保存冲突（文件在编辑期间被外部修改）→ 提示并提供「查看差异 / 覆盖 / 放弃」。
* **需求**：REQ-CFG-002 … REQ-CFG-023。

---

### PG-016 模组与插件

* **区块顺序**：页头（左：标题；中：搜索；右：上传 / 刷新）→ Windows 文件锁告警条（条件显示）→ 标签页（模组 / 插件）→ 表格。
* **表格列**：图标、名称、版本、加载器、状态（启用/停用）、大小、操作。
* **行动作**：启用/停用、查看详情、打开关联配置、删除。
* **状态**：实例运行中时删除禁用、停用带警告。
* **错误**：`file-locked` 专门文案。
* **空态**：「未发现模组」+「上传模组」。
* **明确不提供**：在线搜索与下载。
* **需求**：REQ-MOD-001 … REQ-MOD-014。

---

### PG-017 计划任务

* **区块顺序**：页头（标题 + 刷新 + 新建任务）→ 任务表格。
* **表格列**：名称、状态、触发方式、下次触发、剩余次数、动作摘要、上次结果、操作。
* **行动作**：启用/停用、立即执行、编辑、查看历史、删除。
* **新建/编辑对话框**
  1. 名称；
  2. 触发方式（固定间隔 / 日历 / 指定时刻）；
  3. 触发参数（按方式切换）；
  4. 执行次数；
  5. 重叠策略（跳过 / 排队 / 并发）；
  6. 动作链（可拖拽排序，每行：动作类型 + 参数 + 删除；最多 10 条）；
  7. 失败处理（中止后续 / 继续）。
* **历史抽屉**：时间、触发来源、逐动作结果、耗时、失败原因。
* **空态**：「还没有计划任务」+「新建任务」。
* **需求**：REQ-SCH-001 … REQ-SCH-050。

### PG-018 实例设置

以对话框或独立页面呈现（Web 为独立页面，Desktop 为对话框），分标签页。

| 标签页 | 字段 | 权限 |
| --- | --- | --- |
| 基础 | 名称、标签、备注、节点（只读）、工作目录（停止时可改） | User 可改名称与标签；工作目录限管理员 |
| 启动 | Java 运行时、最小堆、最大堆、附加 JVM 参数、启动方式（JAR / argfile）、路径、服务端参数、环境变量、运行账户凭据别名、命令行预览；别名列表只显示 Agent 上已登记的非秘密元数据，不提供密码输入 | 管理员 |
| 启动（高级） | 高级原始命令（参数数组编辑器） | 仅管理员且全局开关已开启 |
| 停止 | 停止命令、停止超时、强制终止等待 | 管理员 |
| 自动启停 | 自动启动、启动延迟、自动重启、最大重启次数、重启间隔 | 管理员 |
| 终端 | 启用伪终端、初始列/行、ANSI 颜色、输入编码、输出编码、换行模式、快捷命令列表 | 管理员 |
| 查询与 RCON | 服务器查询开关/地址/端口、RCON 开关/地址/端口/密码 | 管理员 |
| 整合内容 | 关联的 Channel、当前 Release、更新动作 | 管理员 |
| 危险区 | 删除登记、删除工作目录（仅受管目录） | 管理员 |

* **破坏性操作**：删除登记（确认 + 说明目录保留）、删除工作目录（确认 + 键入实例名）。
* **需求**：REQ-INS-013 … REQ-INS-015、REQ-INS-060 … REQ-INS-066、REQ-INS-080、REQ-INS-081、REQ-TRM-002、REQ-TRM-011、REQ-TRM-023、REQ-TRM-024、REQ-HMC-060。

### PG-019 新建实例向导

* **权限**：Administrator。
* **步骤**
  1. 选择创建方式：新建空实例 / 上传归档 / 附加已有目录；
  2. 基本信息：名称、节点、标签、备注；
  3. 内容：按方式显示（归档上传控件 / 目录路径输入 + 校验结果 / 无）；
  4. 运行配置：Java 运行时、启动配置（结构化）、停止命令与超时；
  5. 确认：摘要（将创建的目录路径、将执行的动作、`OwnedByServitium` 标记）。
* **布局**：宽屏双栏（左：步骤说明与提示；右：表单），窄屏单列。
* **错误**：`instance-path-invalid`、`instance-path-conflict`、`archive-unsafe`、`java-runtime-invalid` 各有专门文案。
* **需求**：REQ-INS-010 … REQ-INS-012、REQ-INS-080。

### PG-020 节点列表

* **区块顺序**：页头（左：标题 + 在线/总数；中：状态与名称过滤；右：刷新 + 生成注册令牌）→ 节点卡片网格 → 分页。
* **卡片字段**：显示名、连接状态徽章、最后心跳、对外地址、实例运行/总数、平台与 Agent 版本、协议版本、节点 ID（可复制）。
* **卡片动作**：查看该节点实例、Java 运行时、强制重连、设置、更多（轮换凭据、移除）。
* **注册令牌对话框**：有效期、预期节点名（可选）→ 生成后展示令牌与控制平面地址（可复制，仅此一次）+ 简明接入步骤。
* **状态**：离线卡片以危险色标注；协议不兼容以专门徽章标注并给出升级指引。
* **空态**：「还没有节点」+「生成注册令牌」。
* **破坏性操作**：轮换凭据（确认）、移除节点（确认 + 说明将影响的实例登记）。
* **明确不提供**：节点级终端、节点级文件管理、镜像管理。
* **需求**：REQ-NOD-001 … REQ-NOD-042。

---

### PG-021 节点详情

* **区块顺序**：页头 → 概览卡片 → 指标图表（CPU、内存、磁盘，最近 24 小时）→ 该节点实例列表 → 节点配置表单（分组）。
* **配置分组**
  * 基础：显示名、备注、标签、对外地址映射；
  * 路径：实例默认基路径、Java 数据目录；
  * 传输：上传速率上限、下载速率上限、URL 下载并发上限、文件任务并发上限、压缩任务并发上限；
  * 终端：输出缓冲上限（字节与行）；
  * 关机：优雅关机开关、等待秒数；
  * 安全：凭据信息（签发时间、最后使用）+ 轮换 / 吊销。
* **需求**：REQ-NOD-002、REQ-NOD-011、REQ-NOD-020、REQ-NOD-031。

---

### PG-022 Java 运行时

* **区块顺序**：页头（标题 + 扫描本机 + 手工添加 + 导入压缩包）→ 运行时表格。
* **表格列**：显示名、版本、主版本、架构、厂商、路径、来源、使用中的实例数、操作。
* **行动作**：查看使用中的实例、取消登记、删除文件（仅导入型）。
* **扫描结果对话框**：候选列表（路径、版本、架构、厂商、是否已登记）+ 多选登记。
* **状态**：扫描中（长操作进度）。
* **错误**：`java-runtime-invalid`、`java-runtime-in-use`、`java-runtime-not-imported`。
* **空态**：「该节点还没有登记 Java 运行时」+「扫描本机」。
* **需求**：REQ-JRE-001 … REQ-JRE-041。

---

### PG-030 用户管理

* **区块顺序**：页头（左：标题 + 用户总数；中：角色与用户名过滤；右：刷新 + 新增用户）→ 用户表格 → 分页。
* **表格列**：选择框、用户名、角色、状态、上次登录、创建时间、身份绑定、已授权实例数、操作。
* **行动作**：编辑、实例授权、重置 TOTP、吊销全部会话、解绑外部身份、禁用/启用、删除。
* **批量动作**：禁用、删除。
* **编辑对话框字段**：用户名、显示名、角色、密码（留空不变）、Windows SID 绑定。
* **状态**：Owner 行的删除、禁用、降级动作不显示。
* **破坏性操作**：删除（确认 + 键入用户名）、吊销全部会话（确认）。
* **需求**：REQ-USR-001 … REQ-USR-005、REQ-DSK-010。

---

### PG-031 用户实例授权

* **首次进入**：安全说明对话框（授权等价于对该实例的完全控制）。
* **区块顺序**：页头（标题 + 目标用户名 + 刷新 + 授权实例）→ 已授权实例表格。
* **表格列**：节点、实例名、实例状态、授权时间、操作（撤销）。
* **授权对话框**：按节点分组的实例选择器，支持搜索与多选。
* **空态**：「该用户尚未被授权任何实例」。
* **需求**：REQ-USR-010 … REQ-USR-012、REQ-IDN-030 … REQ-IDN-032。

---

### PG-032 个人设置

* **标签页**
  * 账户：显示名、界面语言、修改密码；
  * 两步验证：绑定状态、绑定/解绑、重新生成恢复码；
  * API Key：列表（名称、创建时间、最后使用、过期时间、作用域、操作）+ 创建（明文仅展示一次）；
  * 身份绑定：外部身份绑定状态、绑定/解绑；Windows 账户绑定（只读展示，由管理员配置）；
  * 会话：活动会话列表（客户端、来源 IP、创建时间、最后活动）+ 撤销。
* **破坏性操作**：解绑两步验证（确认）、吊销 Key（确认）、撤销会话（确认）。
* **需求**：REQ-IDN-020、REQ-IDN-025 … REQ-IDN-027、REQ-IDN-056、REQ-IDN-057、REQ-IDN-012。

---

### PG-040 仪表盘

* **可编辑**：进入编辑模式后可拖拽、调整宽高、隐藏、新增卡片。
* **默认卡片顺序与宽度**
  1. 节点状态（3）
  2. 实例状态（3）
  3. 会话状态（3）
  4. 系统状态（3）
  5. 系统信息（12，中）
  6. 操作日志（4，中）
  7. 节点概览（8，中）
  8. 请求量图表（6，小）
  9. 实例数图表（6，小）
* **可新增卡片类型**：文本、图片、链接、时钟、空白、内嵌（白名单）、节点概览、操作日志、实例状态、图表。
* **编辑模式**：所有业务动作禁用；提供保存与重置。
* **需求**：REQ-USR-020 … REQ-USR-025、REQ-USR-040 … REQ-USR-046。

---

### PG-041 系统设置

* **分组导航**：基础、外观、安全、身份、关于。
* **表单模式**：每项为「小标题 + 说明 + 控件」的纵向排列；每组底部独立保存；有未保存修改时切换分组给出确认。
* **基础**：界面语言、监听地址、监听端口、路径前缀、对外基址、展示时区、数据目录（只读）。
* **外观**：侧栏位置、页面标题、登录页文本、Logo（上传/清除）、背景图（上传/清除）、仪表盘编辑入口、仪表盘重置。
* **安全**：允许的跨域来源、响应压缩、可信代理模式与网段与代理头、TLS 证书来源与配置、TOTP 漂移容忍、登录限流阈值、登录 IP 校验、普通用户文件管理开关、API Key 总开关、并发上限（压缩/下载/上传）、URL 下载私有源白名单、会话有效期、**高级原始命令模式总开关**、内嵌卡片来源白名单。
* **身份**：OIDC 开关、提供方显示名、提供方图标、Issuer、Client ID、Client Secret、回调地址、Scope、自动跳转、身份映射字段、测试连接。
* **关于**：版本、构建号、许可、仓库链接、文档链接、导出诊断信息、立即备份数据库（仅 Owner）。
* **生效标注**：每项标注「立即生效」或「需要重启服务」。
* **破坏性/高风险确认**：监听地址改为非回环（强制前置条件校验）、身份配置变更、开启高级原始命令模式、重置仪表盘。
* **需求**：REQ-USR-050 … REQ-USR-062、REQ-SEC-020、REQ-SEC-021。

### PG-042 操作日志

* **区块顺序**：页头（标题 + 过滤 + 导出）→ 日志表格 → 分页。
* **过滤**：时间范围、用户、对象类型、对象、动作、结果。
* **表格列**：时间、用户、动作、对象、结果、来源 IP、详情（展开）。
* **需求**：REQ-USR-030。

### PG-043 安全审计

* 结构同 PG-042，但**无任何编辑或删除入口**。
* **过滤**：时间范围、用户、事件类别、结果。
* **表格列**：时间、事件类别、用户、目标、结果、来源 IP、详情。
* **需求**：REQ-USR-032。

### PG-044 长操作

* **区块顺序**：页头（过滤）→ 操作表格。
* **表格列**：类型、目标、发起者、状态、进度、开始时间、耗时、操作（查看详情、取消）。
* **详情抽屉**：阶段时间线、进度、结果或错误、关联对象链接。
* **需求**：REQ-PLT-020。

### PG-060 分发总览

* **区块顺序**：页头（标题 + 搜索 + 新建 Channel）→ Channel 卡片或表格。
* **字段**：显示名、slug、可见性、当前 Release 序号与版本、文件数、总大小、上次发布时间、最近 7 天请求数、完整性状态。
* **动作**：查看详情、新建发布、编辑、删除。
* **状态**：无生效 Release 的 Channel 以警示样式标注；完整性巡检发现问题时以危险样式标注。
* **空态**：「还没有分发通道」+「新建 Channel」。
* **需求**：REQ-HMC-001、REQ-HMC-050。

---

### PG-061 Channel 详情

* **区块顺序**
  1. 概览（显示名、slug、可见性、关联实例）；
  2. **分发链接**（完整 URL，以 `server-manifest.json` 结尾，可复制；令牌保护时另附说明）；
  3. 当前 Release 摘要（序号、名称、版本、游戏版本、加载器、文件数、总大小、发布时间、发布者）；
  4. Release 历史表格（序号、名称、版本、创建时间、文件数、状态、操作：查看 / 回滚）；
  5. 访问统计图表（最近 7 天与 30 天：manifest 请求、文件请求、传输字节、唯一来源、错误数）；
  6. 设置（显示名、描述、保留数量、关联实例、可见性、令牌轮换）。
* **主要动作**：新建发布。
* **破坏性操作**：切换可见性（确认 + 键入显示名）、轮换令牌（确认 + 键入显示名 + 明示玩家需重新安装）、删除 Channel（确认 + 键入显示名）。
* **需求**：REQ-HMC-001、REQ-HMC-021、REQ-HMC-040、REQ-HMC-041、REQ-HMC-050。

---

### PG-062 新建发布

* **步骤**
  1. 内容来源：上传归档 / 从关联实例的工作目录采集；
  2. 上传或采集（长操作，进度）；
  3. 检查结果：归档安全检查与内容检查的结论；有问题时逐条列出并阻断；
  4. 过滤预览：被排除清单剔除的条目及原因（可折叠列表）；
  5. 元数据表单：名称、作者、版本、描述、游戏版本（必填）、加载器（可选，最多一个模组加载器 + 可选 OptiFine）；
  6. 差异预览：将新增 / 将覆盖 / 将删除三组清单与数量；加载器变更提示；
  7. 确认：当「将删除」非空或加载器变更时要求键入 Channel 显示名。
* **主要动作**：创建 Release 并发布 / 仅创建不发布。
* **错误**：`archive-unsafe`、`archive-too-large`、`hmcl-release-validation-failed` 各有专门文案并列出全部问题条目。
* **需求**：REQ-HMC-002 … REQ-HMC-012、REQ-HMC-020。

### PG-063 Release 详情

* **区块顺序**：元数据 → 文件清单表格（路径、大小、SHA-1；可搜索、可分页）→ manifest 预览（只读 JSON，可复制）→ 使用历史（曾在哪些时间段生效）。
* **主要动作**：回滚到此 Release（仅当非当前）。
* **需求**：REQ-HMC-010、REQ-HMC-021。

* **内容**：仅允许文本、图片、链接、时钟卡片。**不得展示任何需要鉴权的数据。**
* **需求**：REQ-USR-045。

## 4. 全局元素

| 元素 | 说明 |
| --- | --- |
| 页头 | 三分区：左（标题与统计）、中（过滤）、右（主操作） |
| 卡片 | 三区：标题、操作、主体 |
| 通知区 | 非阻塞提示条；错误可展开查看详情与 `traceId` |
| 长操作指示 | 全局角标显示进行中的操作数，点击进入 PG-044 |
| 连接状态指示 | 实时连接断开时在页头显示提示条并自动重连 |
| 确认对话框 | 普通确认 / 危险确认（危险色主按钮）/ 键名确认（要求键入名称） |
| 空态 | 图标 + 一句说明 + 一个主操作 |
| 加载态 | 骨架屏；长操作使用进度条与阶段文本 |
| 权限不足 | 独立说明页，不使用 404 掩盖 |

## 5. 状态词表

界面中的状态取值固定，两种语言的文案见 `../design/principle-localization.md` 术语表。

| 对象 | 状态 |
| --- | --- |
| 实例 | 已停止、启动中、运行中、停止中、忙碌、已崩溃、不可达 |
| 节点 | 在线、离线、协议不兼容、已吊销 |
| 长操作 | 等待中、进行中、已成功、已失败、已取消 |
| 计划任务 | 已启用、已停用 |
| 用户 | 正常、已禁用 |
| Channel | 正常、无生效版本、完整性异常 |
| 模组 | 已启用、已停用、元数据不可读 |

## 6. 双端一致性契约

`Servitium.Contracts` 中维护一份机器可读的界面契约，内容为：页面编号、路由、权限、区块顺序、字段键、动作键、状态键、文案键。

两端在测试中从该契约生成实际页面的清单并逐项比对（`REQ-DSK-050`）。差异只允许出现在契约中显式标注为「平台专属」的条目。
