# Desktop 以 UI 契约驱动页面并在本地执行最小权限预检查

## 状态

已被 adr-15 取代

## 背景

逐页手写壳层容易出现字段漂移和空占位；仅依赖 Server 拒绝会让普通用户先进入危险页面，降低可理解性但不能取代后端安全边界

## 决策

30 个页面由共享 `ui-contract.json` 描述字段、动作和状态，Desktop 使用统一页面模型与动作分派；页面进入前按角色和精确实例 grant 做最小预检查，Server 仍执行最终授权

## 后果

共享契约和 Client 保持协议边界并让 30 页可系统审计；本地预检查改善信息架构，后端复核避免把客户端当作可信边界

原决策编号 DL-013；当前实现不足见技术债，规则与版本值不在此重复定义。
