# 隔离测试使用双回环监听分离 REST 与 Agent gRPC

## 状态

已接受

## 背景

本机测试既要运行 WinUI REST 客户端和真实 Agent 双向 gRPC，又不能信任开发证书、修改系统证书库或开放非回环地址

## 决策

默认 Server 仍只监听一个回环 HTTP 地址；隔离开发测试可配置第二个仅回环 HTTP/2 明文端口承载 Agent gRPC，REST 保持 HTTP/1.1 回环端口

## 后果

双回环端口无需管理员权限和系统修改，并能实际运行两个宿主进程；非回环 TLS/可信代理规则不受影响

原决策编号 DL-008；当前实现不足见技术债，规则与版本值不在此重复定义。
