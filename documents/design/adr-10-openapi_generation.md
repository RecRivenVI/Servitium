# OpenAPI 由端点元数据生成并反向约束共享 Client

## 状态

已接受

## 背景

仅检查路由名称会让 145 个路径看似存在，但所有操作仍可能退化为无模型 `200`，无法生成类型安全客户端

## 决策

Minimal API 路由声明准确的请求、成功响应、文件流和 Problem Details 元数据；生成器据此产出 Client 操作契约，并同时检查 OpenAPI 中没有 Client 未覆盖的操作、Client 中没有 OpenAPI 不存在的操作

## 后果

端点元数据是运行时语义的最近来源，双向集合校验能防止 Server 与 Client 任一侧静默漂移，生成产物不掩盖源契约缺失

原决策编号 DL-011；当前实现不足见技术债，规则与版本值不在此重复定义。
