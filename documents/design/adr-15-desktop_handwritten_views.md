# Desktop 采用手写视图与可测试页面状态

## 状态

已接受

## 背景

用户认可外部评审的界面方向，并于 2026-10-22 将两轮合并，授权补齐原型展示的后端能力。统一字段生成表单不能表达实例工作区、终端、文件表格及分类设置的层级，也让原生响应布局与命令状态难以独立验证。

## 决策

首轮导航、认证、实例工作区及设置使用手写 XAML 和 CommunityToolkit.Mvvm ViewModel，配置和设置使用 SettingsCard/SettingsExpander。共享 UI 契约继续约束字段、动作、状态与权限语义，不再生成首轮布局。Server/Agent 的授权、安全不变量与 CSRF 保持不变；原型能力通过兼容字段和新迁移补齐，协议、测试与文档同步。

首轮检查点后继续节点、分发、用户与活动的手写页面；全部页面迁出后删除 ContractPage 与字符串动作分派。新增后端能力限于原型清单；Web、真实样本与交付继续暂停。

## 后果

页面按真实任务组织，状态和命令可单测；两种呈现并存期间须复核导航、返回、连接切换和授权撤回。字段不是布局来源后，需要逐页原生运行与截图，测试数量不能替代实际可用性。取代 [adr-12](adr-12-desktop_contract.md)，剩余债务见[Desktop 技术债](../project/debt-desktop.md)。
