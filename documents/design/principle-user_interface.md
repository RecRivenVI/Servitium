# 界面原则

Desktop 使用 WinUI 3、Fluent 2 与 CommunityToolkit SettingsCard/SettingsExpander。当前首轮页面采用手写 XAML 和独立 ViewModel；契约约束字段、动作、状态与权限语义，不生成布局。实现边界见 [Desktop 机制](mechanism-desktop.md)，本轮覆盖与缺少的数据见[实施计划](../project/plan-desktop_round_one.md)。Web 尚未开始，仍以 Fluent UI React v9 为目标，不以本轮 Desktop 自查代表双端验收。

## 页面与导航

默认进入实例工作区。主导航为实例、节点、分发、用户，底部为活动与日志、设置；用户入口仅在具备管理权限且服务器有多个账户时出现。初始化、登录、两步验证为无导航的居中单列表单，主按钮位于末尾。

标题栏显示当前连接名称与地址、全局搜索和进行中数量。窄窗口折叠导航、隐藏应用品牌标题并将搜索收为按钮，保留连接识别；Ctrl+K 打开当前搜索入口。返回须恢复页面与所选资源，连接切换须清空旧会话数据、搜索和返回栈。

实例按节点分组，列表保留原生多选。详情由实例标题、状态、副标题、生命周期 CommandBar 和六个标签组成。宽窗口并列列表与内容，窄窗口通过覆盖面板选择实例；配置列表、控制台检查栏及设置分类采用同样的渐进布局。计划编辑在宽窗口位于右侧，窄窗口占据可用内容宽度。表格保留必要字段并允许滚动，不通过压小文字容纳全部列。

## 原生样式

颜色、字体、间距、边框和背景取 WinUI 主题资源，不自建像素令牌或配色。使用 Grid 的弹性列约束长名称，必要时换行或省略并提供完整工具提示。内容高度随实际根布局变化，不缓存旧窗口尺寸。

状态同时用图标、文字与语义颜色表达。运行、停止、崩溃、不可达在列表、标题、检查栏一致；主题切换使用 XAML ThemeResource，并同步原生标题栏按钮主题。仅图标按钮提供可访问名称和工具提示。SettingsCard 使用内联简单值，多行文本和秘密使用纵向内容、横向拉伸；SettingsExpander 只负责可理解的分组。

## 状态与动作

- 加载使用 ProgressBar/ProgressRing，正在提交时禁止重复动作。
- 空状态说明为什么为空，并给出当前可执行的下一步。
- 错误使用本地化原因与下一步；未知响应不直接展示异常、内部键、GUID 或修订号。
- 权限撤回立即清除旧内容，不允许未保存提示阻止授权收回。Server 与 Agent 始终执行最终复核。
- 节点离线保留实例登记并说明等待恢复；崩溃只展示实际退出信息，不推测崩溃时间或原因。
- 强制终止、删除登记、目录删除和身份撤销收进溢出区并确认，写清影响。外部目录永不提供递归删除入口。
- 长操作展示真实阶段、结果与可用的暂停/取消能力；请求被接受不等于执行成功。

实例配置、计划及设置保存前校验，未保存时显示摘要，切换页面、实例、分类或连接前确认。并发修订仅用于内部条件请求，冲突不得默默覆盖。不能使用条件更新的现有契约限制单列为技术债。

## 用户语言与能力边界

界面使用名称和用户任务词汇，作用范围就地说明。本应用偏好只影响此电脑；服务器设置影响所有连接者；账户设置作用于当前用户。简体中文与英文键集合同步，生成 resw 只经生成入口更新。

不填原型示例数据。没有版本、加载器、历史曲线、文件锁或崩溃时间时明确未提供；不能按名称、进程或时间差猜出协议没有的信息。第三方终端/编辑器自身的标准菜单随其原包，宿主标签与按钮使用本地化资源。

## 键盘与可访问性

| 操作 | 入口 |
| --- | --- |
| 焦点移动 | Tab、Shift+Tab |
| 全局搜索 | Ctrl+K |
| 返回 | Alt+左方向键与标题栏返回 |
| 刷新 | F5 或页面刷新按钮 |
| 表单与文本保存 | Ctrl+S、原生保存按钮 |
| 终端命令 | 输入框 Enter 或发送 |
| 对话框与面板 | Esc 或明确关闭按钮 |

保留 WinUI 原生焦点和控件语义。系统 DPI、文本放大、读屏、高对比度与动效仍需相应真实环境验证，不能从自动化元素存在推定通过。截图只取自有窗口，深浅色用应用设置切换；验证范围和人工检查见[首轮场景](../../validations/ui-desktop_round_one/validation.md)。
