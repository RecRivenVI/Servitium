# 共享界面规格

本文件定义 Desktop 与 Web 共用的设计体系、组件语义、交互模式与无障碍要求。页面结构见 `../design/architecture-information.md`。

设计体系为 **Fluent 2**。Desktop 使用 WinUI 3 与 Windows App SDK 的原生控件；Web 使用 Fluent UI React v9。两端**不复用** MCSManager 的任何控件、颜色、图标、样式、资源或文案。

## 1. 设计令牌

两端使用同一套语义令牌名，各自映射到平台原生实现。

### 1.1 颜色语义

| 令牌 | 用途 |
| --- | --- |
| `surface.page` | 页面背景 |
| `surface.card` | 卡片背景 |
| `surface.raised` | 浮层、对话框、下拉 |
| `stroke.divider` | 分隔线 |
| `stroke.control` | 控件边框 |
| `text.primary` | 主要文本 |
| `text.secondary` | 次要文本与说明 |
| `text.disabled` | 禁用文本 |
| `accent.primary` | 主操作与选中态 |
| `status.success` | 运行中、成功 |
| `status.caution` | 启动中、停止中、忙碌、警告 |
| `status.danger` | 已崩溃、失败、破坏性操作 |
| `status.neutral` | 已停止、未知、不可达 |
| `status.info` | 提示 |

主题：跟随系统的浅色与深色；跟随系统强调色。不提供自定义配色。

### 1.2 间距与圆角

间距标度：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`（像素或有效像素）。

圆角：控件 `4`，卡片 `8`，浮层 `8`。

### 1.3 排版

| 层级 | 用途 |
| --- | --- |
| `title.large` | 页面标题 |
| `title.medium` | 卡片标题、对话框标题 |
| `title.small` | 分组标题、表单小标题 |
| `body.strong` | 强调正文、表格列头 |
| `body` | 正文 |
| `caption` | 说明文字、时间戳 |
| `mono` | 终端、路径、哈希、代码 |

等宽字体族：Desktop 使用 `Cascadia Mono`，回退 `Consolas`；Web 使用同名字体族并回退到系统等宽栈。

## 2. 栅格与响应式

12 栅格。断点（视口有效宽度）：

| 断点 | 范围 | 行为 |
| --- | --- | --- |
| `xs` | < 640 | 单列；页面标题隐藏；动作收进溢出菜单；表格转卡片列表；导航为抽屉 |
| `sm` | 640–899 | 两列卡片；表格保留关键列并可横向滚动 |
| `md` | 900–1199 | 三列卡片；导航可折叠 |
| `lg` | 1200–1599 | 四列卡片；导航展开 |
| `xl` | ≥ 1600 | 六列卡片；内容区限制最大宽度 |

Desktop 的窗口宽度直接映射到同一断点表，保证两端在同宽度下呈现一致（`DEC-05`）。

## 3. 组件语义

### 3.1 页头

三分区：

```text
[ 左：标题 + 统计 ]   [ 中：过滤与搜索 ]   [ 右：主操作 ]
```

* 左区在 `xs` 隐藏；
* 中区在 `xs` 占满宽度；
* 右区最多一个主按钮（`accent`），其余为次要按钮或溢出菜单；
* 面包屑位于页头之上，`xs` 时仅显示返回按钮。

### 3.2 卡片

三区：标题、操作、主体。标题左对齐；操作右上角；主体可滚动。卡片有描述时置于标题下方，使用 `caption`。

### 3.3 表格

* 列定义包含：键、标题、对齐、宽度或权重、是否可排序、是否在窄屏保留；
* 首列可为选择框（支持批量时）；
* 末列为操作列，右对齐；
* 行高统一；
* 支持行内展开（用于详情）；
* 空态、加载骨架、错误态在表格主体内呈现；
* 大数据量使用虚拟滚动。

### 3.4 状态徽章

状态以「颜色 + 图标 + 文本」三重编码，不以颜色单独表达。

| 状态 | 语义色 | 图标语义 |
| --- | --- | --- |
| 运行中 / 在线 / 已成功 / 已启用 | `status.success` | 实心圆点或对勾 |
| 启动中 / 停止中 / 忙碌 / 进行中 | `status.caution` | 进度环 |
| 已停止 / 已停用 / 等待中 | `status.neutral` | 空心圆点 |
| 已崩溃 / 已失败 / 已吊销 / 完整性异常 | `status.danger` | 感叹号 |
| 不可达 / 协议不兼容 | `status.neutral` + 斜纹 | 断开连接 |

### 3.5 按钮层级

| 层级 | 用法 |
| --- | --- |
| 主要（accent） | 每个页面或对话框至多一个 |
| 次要 | 常规动作 |
| 微妙（subtle） | 图标按钮、行内动作 |
| 危险 | 破坏性动作；仅在确认对话框中作为主按钮出现 |

仅图标的按钮必须有工具提示与可访问名称。

### 3.6 对话框

| 类型 | 用法 |
| --- | --- |
| 信息 | 单一说明 + 关闭 |
| 确认 | 说明 + 取消 + 确认 |
| 危险确认 | 说明「会发生什么」与「是否可撤销」 + 取消 + 危险主按钮 |
| 键名确认 | 危险确认 + 要求键入目标名称，键入正确前主按钮禁用 |
| 表单 | 分组表单 + 取消 + 提交；提交中禁用 |
| 向导 | 步骤条 + 上一步/下一步/完成 |

**键名确认**适用于：删除工作目录、删除用户、删除 Channel、轮换 Channel 令牌、切换 Channel 可见性、发布含删除项或加载器变更的 Release、移交 Owner。

### 3.7 面板与抽屉

用于详情查看（长操作详情、计划任务历史、日志详情）。从右侧滑入，宽度 `min(480px, 100%)`，可通过 `Esc` 关闭。

### 3.8 通知

| 形式 | 用法 |
| --- | --- |
| 内联提示条 | 页面级持续状态（连接断开、Windows 文件锁警告、Channel 完整性异常） |
| 浮动提示 | 操作结果（成功 3 秒自动消失；失败需手工关闭并可展开详情） |
| 系统通知 | 仅 Desktop，见 `../design/mechanism-desktop.md` |

失败提示必须包含：一句话原因（按错误码本地化）+ 可展开的 `traceId` 与 `detail`。

### 3.9 进度

| 场景 | 形式 |
| --- | --- |
| 页面加载 | 骨架屏 |
| 短操作 | 按钮内旋转指示 |
| 长操作（有进度） | 确定性进度条 + 阶段文本 + 取消按钮 |
| 长操作（无进度） | 不确定进度条 + 阶段文本 + 取消按钮 |
| 传输任务 | 进度条 + 速率 + 剩余时间 + 暂停/取消 |

### 3.10 空态

结构固定：图标 + 一句说明（说明「为什么空」而非「没有数据」）+ 至多一个主操作。

### 3.11 权限不足

独立说明区块：图标 + 「你没有访问该内容的权限」+ 返回可访问页面的按钮。**不以 404 掩盖**，因为掩盖会让用户误以为对象不存在。

### 3.12 终端

* 等宽字体，字号可调（12–20）；
* ANSI SGR 渲染（可按实例关闭）；
* 自动滚动，向上滚动时暂停并显示「回到底部」按钮；
* 搜索（`Ctrl+F`）、清屏、复制全部、导出；
* 输入框支持历史（上下键）与快捷命令按钮组；
* 观察者数量显示在页头；
* 缓冲被截断时插入可见的标记行。

### 3.13 代码编辑器

Monaco。要求：

* 行号、当前行高亮、缩进指示；
* 按扩展名的语法高亮（properties、json、yaml、toml、log、纯文本）；
* `Ctrl+S` 保存；
* 显示编码与行尾模式，可切换；
* 有未保存修改时页头显示标记且离开需确认；
* 只读模式用于 manifest 预览。

### 3.14 文件选择与拖放

Web：`<input type="file">`（含目录选择）+ 拖放到列表区。
Desktop：系统文件对话框 + 从资源管理器拖放。

两端的上传行为、进度呈现与冲突处理一致。

## 4. 交互模式

编号与 `../research/survey-mcsmanager_layout.md` 第 3 节对应，此处给出 Servitium 的实现约定。

| 编号 | 模式 | 约定 |

| UX-01 | 三分区页头 | 见 3.1 |
| UX-02 | 三区卡片 | 见 3.2 |
| UX-03 | 列表页双行工具栏 | 第一行过滤与主操作；第二行批量与分页 |
| UX-04 | 批量模式 | 通过选择框进入；工具栏切换为批量动作；提供「退出选择」 |

| UX-11 | 多标签目录 | 文件管理最多 8 个标签 |

| UX-13 | 分组表单独立保存 | 每组底部一个保存按钮；未保存时切组给出确认 |

| UX-20 | 平台告警条 | Windows 文件锁提示 |

## 5. 键盘与快捷键

两端一致。

| 快捷键 | 作用 | 范围 |
| --- | --- | --- |
| `Ctrl+S` | 保存 | 编辑器与表单页 |
| `Ctrl+F` | 搜索 | 终端与编辑器 |
| `Esc` | 关闭对话框 / 抽屉 / 取消路径编辑 | 全局 |
| `Enter` | 提交焦点表单 | 表单 |
| `F5` | 刷新当前列表 | 列表页 |
| `Ctrl+K` | 打开命令面板（跳转页面、搜索实例） | 全局 |
| `↑` / `↓` | 命令历史 | 终端输入框 |
| `Tab` / `Shift+Tab` | 焦点移动 | 全局 |

所有交互必须可仅用键盘完成。

## 6. 无障碍

| 要求 | 说明 |
| --- | --- |
| 对比度 | 正文与背景至少 4.5:1；大号文本与图形至少 3:1 |
| 焦点可见 | 所有可交互元素有清晰的焦点指示，不得移除 |
| 语义角色 | 表格、列表、对话框、导航使用正确的语义角色 |
| 可访问名称 | 仅图标的控件必须有本地化的可访问名称 |
| 状态非纯色 | 状态同时用图标与文本表达 |
| 实时区域 | 操作结果与连接状态变化通过实时区域播报 |
| 动效 | 尊重「减少动效」系统设置 |
| 缩放 | Web 支持 200% 缩放不丢失内容；Desktop 跟随系统 DPI 与文本缩放 |

## 7. 文案

* 文案键与规则见 `../design/principle-localization.md`；
* 界面中不出现硬编码的用户可见字符串；
* 服务端错误按 `code` 本地化；未知 `code` 回退到通用失败文案并展示 `traceId`；
* 破坏性操作的确认正文必须写明「会发生什么」与「是否可撤销」；
* 空态说明必须解释「为什么空」。

## 8. 数据格式化

| 类型 | 规则 |
| --- | --- |
| 时间 | 相对时间（< 7 天）或绝对时间；悬浮显示完整 UTC 与本地时间 |
| 时长 | 按量级选择单位（秒 / 分 / 时 / 天） |
| 字节 | 二进制单位（B、KiB、MiB、GiB、TiB），保留 1–2 位小数 |
| 速率 | 十进制单位（B/s、kB/s、MB/s） |
| 百分比 | 整数或 1 位小数 |
| 路径 | 等宽字体；过长时中间省略并保留首尾；可复制 |
| 哈希 | 等宽字体；默认显示前 12 位，可展开与复制 |
| 标识（`Guid`） | 等宽字体；默认显示前 8 位，可复制完整值 |

## 9. 图标

使用 Fluent 图标体系。图标语义在契约中登记（键 → 语义名），两端各自映射到平台图标资源。不引入第三方图标包，不复用参考项目的图标。

## 10. 错误呈现规范

| 层级 | 呈现 |
| --- | --- |
| 字段级 | 控件下方红色说明，聚焦到首个错误字段 |
| 表单级 | 表单顶部汇总条 |
| 操作级 | 浮动失败提示 + 可展开详情 |
| 页面级 | 内联提示条或独立说明页 |
| 连接级 | 页头持续提示条 + 自动重连状态 |

所有错误呈现必须提供 `traceId` 以便与服务端日志关联。

## 11. 性能预算

| 指标 | 目标 |
| --- | --- |
| Web 首屏可交互 | 本地网络 < 2 秒 |
| 列表页首次渲染（50 条） | < 300 毫秒 |
| 终端输出渲染延迟 | < 100 毫秒（从收到到显示） |
| 表格滚动 | 60 fps（虚拟滚动） |
| Desktop 冷启动到可交互 | < 3 秒 |
| Desktop 页面切换 | < 200 毫秒 |

## 12. 一致性守护

`Servitium.Contracts` 中的界面契约文件登记：页面编号、路由、权限、区块顺序、字段键、动作键、状态键、文案键、是否平台专属。

两端测试从该契约生成实际清单并比对（`REQ-DSK-050`）。新增页面或字段必须先更新契约（受保护文档变更流程）。
