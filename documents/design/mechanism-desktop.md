# Desktop 机制

Desktop 是 Windows 11 x64 原生 WinUI 3 客户端，所有服务器数据和操作通过 Servitium.Client 访问 Server，不直连 Agent、数据库或实例目录。关闭客户端不停止服务端、节点或实例。

## 视图与导航

MainWindow 承载原生 TitleBar、NavigationView 与内容区。ShellViewModel 管理导航可见性、当前连接、搜索、进行中数量和连接提示；视图代码负责窗口、焦点、导航与响应布局。默认实例入口汇总运行状态，取消独立仪表盘导航。

本轮登录组、实例工作区及六标签、三步创建、分类设置采用各自 XAML 和可测试 ViewModel。节点、分发、用户、活动当前仍使用 ContractPage/动作分派；已获授权在本轮改写并移除。采用边界见 [adr-15](adr-15-desktop_handwritten_views.md)。

返回栈保存页面及所选资源。离开编辑页先执行 INavigationGuard；连接切换取消旧连接范围任务、退订事件、清除选择、搜索和返回历史。授权变化仅在当前身份或 grant 实际变化时重建内容，撤回不受脏数据确认阻挡。第二轮页面保留既有权限与动作。

## 工作区

实例列表读取完整分页、按节点分组与筛选；普通用户只获得已授权集合。刷新用实例标识恢复原生多选，实际焦点对象与批量集合分开处理。生命周期按钮依角色、节点在线性、实例状态与忙碌状态启用。操作等待真实完成结果。

控制台复用受限 WebView2/xterm；宿主读取真实状态、指标和玩家查询，不构造历史曲线。文件管理限定于所选实例根，复用现有传输服务的分块校验、暂停、取消和长操作等待。Monaco 就绪后加载文本，全部修改更新脏状态，只有写入成功才确认保存。

配置用显式 SettingsCard 映射内置 schema，未知键保留，保存携带期望修订；原始文本与结构化视图共享草稿。模组只管理当前实例已有文件。计划任务表格与编辑面板保留触发器、动作顺序、剩余次数和重叠策略，单项读取使用现有 Agent 列表能力。

实例设置完整加载后才允许编辑；未编辑的可选配置块原样保存，不将 null 无意改为空集合。外部工作目录只允许删除登记并保留文件，受管目录删除按原安全校验及确认执行。

## 分类设置

| 范围 | 分类 |
| --- | --- |
| 此电脑 | 外观与语言、终端、通知与托盘、服务器连接 |
| 当前服务器，需管理权限 | 常规、安全、身份登录、关于与备份 |
| 当前用户 | 账户与安全 |

各分类使用独立草稿和保存范围。服务器设置只提交变化字段及期望修订；秘密默认空白代表保留，明确清除才提交删除。敏感暴露、OIDC 与高级命令变更沿用确认。账户页包含资料、密码、两步验证、恢复码、OIDC、API 密钥和会话，秘密只在创建或登记时短暂展示。

连接配置是本机名称和地址，不存凭据；未登录或连接失败时仍可从标题栏管理。活动连接删除前必须先切换到其他连接，不把本机列表删除解释为删除服务器。

## 窗口与本机生命周期

主题从本机偏好应用到 XAML 根与原生 AppWindow 标题栏；独立终端使用相同主题服务。响应布局取实际根大小，窄窗口折叠导航及搜索，宽窗口释放列表与检查栏空间。窗口几何恢复校正在可见显示区域。

普通启动使用应用单实例重定向；隔离运行按独立数据根命名实例注册和凭据资源，避免测试激活真实客户端。本地偏好保存在用户应用数据目录，令牌使用 Windows 凭据管理器。测试路径由明确的隔离环境变量提供，不改变系统配置。

托盘提供显示主窗口、近期实例生命周期、暂停通知、关于与退出；关闭到托盘由本机设置控制，首次有说明。通知沿用现有分类、聚合、专注状态排队与深链接；本轮只重排其偏好入口。退出与关闭仍遵守服务继续运行的边界。

## 终端与编辑器边界

WebView2 仅载入打包的本地资源，拒绝外部导航、新窗口和通用宿主对象；宿主传输白名单消息，不把会话 Cookie 暴露给页面。实时连接沿用同一会话及 CSRF 认证。独立终端由既有窗口服务管理，关闭窗口不停止实例。

这里描述当前生产边界，不表示系统通知、拖放、读屏或全部 Windows 平台已重新验收；实际证据及剩余限制见[技术债](../project/debt-desktop.md)和[验证定义](../../validations/ui-desktop_round_one/validation.md)。
