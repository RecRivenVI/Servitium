# Desktop 界面规格

`Servitium.Desktop`：Windows 11 x64 上的 WinUI 3 客户端。

页面结构见 `../design/architecture-information.md`；共享设计体系见 `../design/principle-user_interface.md`。本文件只定义 Desktop 特有的部分。

## 1. 定位

Desktop 只负责用户交互、托盘与通知。它**不包含任何业务逻辑**，不直接访问数据库、实例工作目录或 Agent；所有数据经 `Servitium.Client` 访问 `Servitium.Server`。

退出 Desktop 不影响 Server、Agent 或任何实例（`REQ-DSK-032`）。

## 2. 应用生命周期

### 2.1 单实例

使用应用实例重定向：启动时检测已有实例，存在则把命令行与激活参数重定向给它并退出。已有实例收到重定向后：若窗口隐藏在托盘则恢复并置前；若已可见则闪烁任务栏并置前。

**验收**：连续启动 3 次，进程数恒为 1，窗口被激活（`REQ-DSK-001`）。

### 2.2 启动序列

```text
应用启动
  → 单实例检查
  → 加载本地设置（上次的服务器地址、语言、主题、通知偏好）
  → 尝试本机换票（仅当服务器地址为本机）
      成功 → 建立会话 → 进入主窗口
      失败 → 显示登录页并说明失败原因
  → 建立实时连接
  → 恢复上次页面（可在设置中关闭）
```

冷启动到可交互目标 < 3 秒。

### 2.3 关闭与退出

| 操作 | 行为 |
| --- | --- |
| 关闭主窗口 | 默认隐藏到托盘；首次关闭时弹出一次性说明（含「不再提示」）；可在设置中改为「关闭即退出」 |
| 托盘菜单「退出客户端」 | 确认对话框，正文明确说明「服务端与实例将继续运行」，然后退出进程 |
| 系统注销或关机 | 直接退出，不弹确认 |

## 3. 窗口与外观

| 项 | 规范 |
| --- | --- |
| 材质 | Mica（`MicaKind.Base`）；系统不支持时回退到纯色 |
| 标题栏 | 自定义标题栏，承载返回按钮、面包屑与全局操作 |
| 主题 | 跟随系统浅色/深色与强调色；可在设置中强制指定 |
| 最小尺寸 | 960 × 640 |
| 记忆 | 窗口位置、尺寸与最大化状态在退出时保存并在启动时恢复；多显示器变化时校正到可见区域 |
| DPI | 跟随系统 DPI 与文本缩放，支持运行时变化 |

## 4. 导航

使用 `NavigationView`：

* 导航项与 `../design/architecture-information.md` 第 2 节的主导航一一对应，顺序相同；
* 展开与折叠状态跟随窗口宽度断点（同 `../design/principle-user_interface.md` 第 2 节）；
* 底部固定区放当前用户菜单；
* 支持返回栈：`Alt+←`、鼠标侧键、标题栏返回按钮；
* 深链接导航（来自通知或托盘）压入返回栈而非替换。

## 5. 托盘

### 5.1 图标状态

| 状态 | 触发条件 |
| --- | --- |
| 正常 | 连接正常且无告警 |
| 有告警 | 存在崩溃实例、离线节点、失败的长操作或 Channel 完整性异常 |
| 已断开 | 与 Server 的实时连接断开 |

图标状态变化不弹出通知（通知由具体事件触发）。

### 5.2 托盘菜单

顺序固定：

1. 显示主窗口
2. ──分隔──
3. 实例（子菜单，最近使用的最多 10 个）
   * 每项为实例名 + 状态图标，其子菜单为：打开控制台、启动、停止、重启
4. ──分隔──
5. 暂停通知（子菜单：30 分钟 / 1 小时 / 直到重启 / 取消暂停）
6. ──分隔──
7. 关于
8. 退出客户端

双击托盘图标等价于「显示主窗口」。

**验收**：托盘菜单项与状态在实例状态变化后 2 秒内更新（`REQ-DSK-030`、`REQ-DSK-033`）。

## 6. 系统通知

### 6.1 通知类别

| 类别 | 触发 | 默认 |
| --- | --- | --- |
| 实例崩溃 | `instance.crashed` | 开 |
| 自动重启耗尽 | `instance.auto-restart-exhausted` | 开 |
| 节点离线 | `node.status-changed` → Offline | 开 |
| 节点恢复 | `node.status-changed` → Online | 关 |
| 长操作完成 | `operation.completed`（成功） | 关 |
| 长操作失败 | `operation.completed`（失败） | 开 |
| 发布完成 | `hmcl.published` | 开 |
| 完整性告警 | `hmcl.integrity-alert` | 开 |

每个类别可在设置中单独开关。

### 6.2 通知内容

标题：事件类型 + 对象名。
正文：一句话说明 + 关键数据（退出码、重启次数、失败原因摘要）。
按钮：至多两个，指向相关页面或直接执行动作（如「重新启动实例」）。

### 6.3 聚合

同一类别的事件在 60 秒窗口内合并为一条通知，展示「N 项 + 最近一条摘要」。点击进入对应的列表页并按该类别过滤（`REQ-DSK-041`）。

### 6.4 深链接

通知携带参数标识目标页面与对象。点击时：

* 应用未运行 → 启动并直接导航；
* 应用在托盘 → 恢复窗口并导航；
* 应用可见 → 导航并置前。

导航目标：实例控制台、节点详情、长操作详情、Channel 详情（`REQ-DSK-042`）。

### 6.5 排队

处于下列情形时通知进入队列而非立即弹出（`REQ-DSK-043`）：

* 用户已在托盘菜单中暂停通知；
* 系统专注助手处于「仅闹钟」或「仅优先」且 Servitium 不在优先列表；
* 系统处于全屏独占。

恢复后以聚合形式一次性呈现。队列上限 50 条，超出时丢弃最旧的非危险类通知。

## 7. 本机免登

见 `../reference/protocol-control_plane.md` 第 7 节与 `../design/security-threat_model.md` THR-006。

Desktop 侧行为：

1. 仅当配置的服务器地址解析为本机时尝试换票；
2. 通过命名管道获取一次性令牌；
3. 用令牌换取会话 Cookie；
4. 会话到期前 2 分钟自动续期（重新走管道）；
5. 换票失败时展示登录页并在顶部说明具体原因（Server 未运行 / 当前 Windows 账户未关联 Servitium 用户 / 客户端未安装在受信路径）。

Desktop 也可连接远程 Server；此时仅支持用户名密码或 OIDC 登录。

## 8. 服务器连接管理

Desktop 支持保存多个服务器配置（地址 + 备注），在登录页与设置中切换。当前连接的服务器名显示在标题栏。

切换服务器等价于登出并重新连接。

## 9. 终端与编辑器

终端与代码编辑器通过受限 WebView2 承载，复用 Web 侧的 xterm.js 与 Monaco 集成，保证两端行为一致。

安全约束见 `../design/security-threat_model.md` THR-090：

* 仅加载本地打包资源，拦截一切外部导航；
* 禁用新窗口与开发者工具（Release）；
* 不注入通用宿主对象，仅暴露白名单消息通道；
* WebView2 内不发起网络请求，数据由宿主传入；
* 不共享 Cookie 与会话。

宿主与 WebView2 之间的消息通道：

| 通道 | 方向 | 载荷 |
| --- | --- | --- |
| `terminal.output` | 宿主 → Web | 输出块 |
| `terminal.input` | Web → 宿主 | 输入文本 |
| `terminal.resize` | Web → 宿主 | 列数与行数 |
| `terminal.settings` | 宿主 → Web | 字号、颜色开关 |
| `editor.load` | 宿主 → Web | 内容、语言、只读标记 |
| `editor.save` | Web → 宿主 | 内容 |
| `editor.dirty` | Web → 宿主 | 是否有未保存修改 |
| `theme.changed` | 宿主 → Web | 浅色/深色与强调色 |

## 10. 独立终端窗口

从实例控制台可打开独立终端窗口：

* 独立窗口有自己的标题（实例名 + 节点名）与位置记忆；
* 关闭独立窗口不影响主窗口与实例；
* 主窗口退出时一并关闭独立终端窗口；
* 最多同时打开 8 个（与并发终端容量目标一致）。

## 11. 拖放

| 目标 | 行为 |
| --- | --- |
| 文件管理页 | 拖入文件或文件夹 → 上传到当前目录（保持相对结构） |
| 模组页 | 拖入 JAR → 上传到对应目录 |
| 新建实例向导（上传归档步骤） | 拖入 ZIP → 作为归档来源 |
| 发布页（上传归档步骤） | 拖入 ZIP → 作为归档来源 |

拖放进入时高亮目标区域并显示将执行的动作。

## 12. 本地设置

存放在 `%LocalAppData%\Servitium\Desktop\settings.json`。内容：

| 项 | 说明 |
| --- | --- |
| 服务器列表与当前选择 | 地址 + 备注；**不存储任何凭据** |
| 界面语言 | 覆盖服务端默认 |
| 主题 | 跟随系统 / 浅色 / 深色 |
| 关闭行为 | 隐藏到托盘 / 退出 |
| 通知类别开关 | 见 6.1 |
| 窗口几何 | 位置、尺寸、最大化 |
| 上次页面 | 用于恢复 |
| 终端字号 | |
| 最近实例 | 用于托盘子菜单 |

会话令牌保存在 Windows 凭据管理器，不写入设置文件。

## 13. 日志

Desktop 日志写入 `%LocalAppData%\Servitium\Desktop\logs\desktop-<yyyyMMdd>.log`，保留 14 天。包含：启动序列、连接状态、导航、错误与 `traceId`。不记录任何秘密。

设置中的「关于」提供「打开日志目录」。

## 15. 与 Web 的差异清单

下列差异是**允许**的（`REQ-DSK-050`）；其余任何差异视为缺陷。

| 差异 | 说明 |
| --- | --- |
| 单实例 | Desktop 独有 |
| 托盘 | Desktop 独有 |
| 系统通知与聚合与排队 | Desktop 独有 |
| 本机免登 | Desktop 独有 |
| 独立终端窗口 | Web 用新标签页 |
| 从资源管理器拖放 | Web 用文件选择与页面内拖放 |
| Mica 与自定义标题栏 | Desktop 独有 |
| 窗口几何记忆 | Desktop 独有 |
| 服务器切换 | Desktop 独有（Web 天然绑定当前站点） |
| 打开日志目录 | Desktop 独有 |

信息架构、字段、动作、状态、权限与文案在两端完全一致。
