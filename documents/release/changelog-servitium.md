# 更新日志

遵循 Keep a Changelog；产品版本取公共构建配置。当前没有正式发布。

## 未发布

### 新增

- 原生实例工作区及控制台、文件、配置、模组、计划任务、设置六标签，三步创建向导与分类设置。
- 居中初始化、登录与两步验证页面；连接管理、全局搜索、进行中入口和本机偏好分类。

### 变更

- 首轮页面采用独立 XAML 与可测试 ViewModel；状态同时使用图形与文字，危险操作归入确认流程。
- 导航默认进入实例，汇总并入列表；节点、分发、用户和活动当前保持现有入口，按合并计划继续改写。

- 更新 Windows App SDK 与配套构建工具，引入 CommunityToolkit SettingsCard/SettingsExpander。
- 采用仓库规范，重组当前文档、脚本、资源和测试项目命名。
- 构建、运行及验证证据外置；保留已有产品行为与用户确认的范围。

### 移除

- 自建门禁/Profile、文档保护/依赖/覆盖检查器和旧永久清理入口。
- 没有调用方的测试客户端与仓库内历史流水、重复映射和运行产物。

### 修复

- 实时终端握手正确携带会话与 CSRF；编辑器持续跟踪全部文本修改，保存成功后才清除未保存状态。
- 普通账户完成两步验证后只建立授权范围事件连接；被拒绝的范围不污染重连，权限变化通知能触发身份刷新。
- 时间查询正确转义 UTC 偏移，关于页与其他日期筛选不再因加号被当成空格而失败。
- 计划任务单项读取使用已存在的节点列表能力；账户会话与密钥列表可在 SQLite 上按实际时间排序。
- 实例设置保留未编辑的可选块；窗口缩放和主题变化同步内容高度、状态图标与原生标题栏。

- 将正式客户端仍使用的错误类型恢复为独立文件，保留服务端错误说明与重试提示。

### 安全

- 更新微软依赖与 ASP.NET Core 运行时安全补丁，解除 SignalR 的高危依赖审计阻断；审计保持开启。
