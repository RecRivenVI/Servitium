# 使用桌面端

你可以连接自己的 Servitium 服务器，管理获授权的 Minecraft Java 实例及本机应用偏好。当前界面仍在开发与验收中。

## 连接与登录

标题栏显示当前服务器的名称和地址。打开下拉菜单可以切换，或选择“管理连接”添加名称和 HTTP/HTTPS 地址；连接失败或未登录时仍可管理。连接列表只保存在这台电脑，删除条目不会删除服务器。切换前若有未保存内容，先保存或明确放弃。

首次连接尚未初始化的服务器时，按居中表单创建所有者；已初始化时输入用户名和密码。启用两步验证的账户继续输入验证码，也可以使用恢复码。登录失败后按提示核对输入和连接。

## 实例工作区

左侧按节点列出你可访问的实例，顶部显示数量与状态汇总。你可以筛选名称和状态，或用原生列表多选；窄窗口先打开“实例”按钮选择。右侧标题与列表使用同样的状态图标。离线登记仍保留，需等待节点恢复。

启动、停止和重启会按状态启用。强制终止在更多操作里，确认前先读清后果。新建实例使用三步向导：选择来源、节点与位置，填写该节点登记的 Java 和启动参数，检查命令预览后提交；等待实际任务结果。

六个标签各自完成一种工作：

| 标签 | 你可以做什么 |
| --- | --- |
| 控制台 | 看输出、输入命令并按 Enter 发送，查看真实指标、玩家查询和实例信息 |
| 文件 | 在此实例工作目录内浏览、上传、下载、编辑和维护文件；编辑器用 Ctrl+S 保存 |
| 配置 | 选择配置文件，切换结构化或原始文本，查看未保存项并保存、还原或查看备份 |
| 模组 | 管理已经放入实例的模组，上传、扫描、启停与删除；不提供在线市场 |
| 计划任务 | 查看任务并在编辑面板内创建、调整、保存、执行或查看历史 |
| 设置 | 按组修改启动、自动启停、终端、查询和整合内容关联；需管理权限 |

文件写入、配置、模组上传或删除需要实例停止；运行时可浏览和下载。模组开关在下次启动生效，被占用时仍可能被拒绝。离开未保存的配置、编辑器或设置时会提示。并发修改冲突后先重新读取，避免覆盖别人的内容。

删除登记会保留工作目录。外部工作目录没有递归删除入口；受管目录的危险操作需要额外确认。终端和文件服务的权限仍由服务器决定，看到页面不代表拥有全部操作权限。

## 设置的作用范围

“设置”左侧分类分为：

- “本应用”：外观与语言、终端、通知与托盘、服务器连接，只影响这台电脑的窗口。语言和终端字号按页面说明在下次启动或新终端生效。
- “服务器”：常规、安全、身份登录、关于与备份，影响所有连接者，只向管理员显示。秘密留空表示保留；要删除必须明确选择清除。
- “我”：账户与安全，修改个人资料、密码、两步验证、登录绑定、API 密钥和会话。新秘密或恢复码只显示一次，请妥善保存。

主题从“外观与语言”切换，不需要修改 Windows 设置。通知可按类别关闭或暂停；关闭到托盘与退出客户端都不会停止服务端或实例。

## 快捷键与问题处理

Ctrl+K 搜索当前可访问的实例、当前实例文件或快捷命令；Alt+左方向键返回，F5 刷新，Tab/Shift+Tab 移动焦点。保存可以使用 Ctrl+S 或页面按钮。

连接中断时按提示检查服务器，再从标题栏重新选择连接。节点离线时等待节点恢复；实例崩溃时依据已报告的原因检查启动或内存配置。界面没有提供的版本、历史曲线或文件占用信息不能当作正常值。

人工验收请按[首轮验收清单](guide-desktop_acceptance.md)一次完成并反馈。两轮重写已合并推进；你确认界面通过后，制作安装包仍需单独授权。
