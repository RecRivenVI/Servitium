# 客户端场景验证

## 目标

验证现有产品的真实场景与安全边界；不以接口或测试数量代替可用性。

## 运行

按开发测试文档使用独立数据库、外部数据根和随机端口；真实服务、权限、第二系统或样本不可用时记录无法比较。Desktop 等待界面设计完成，Web 暂停，不启动在用服务。结果放在仓库外。

## 通过标准

以下保留现有场景编号与业务标准；旧阶段编号仅作为需求定位，不恢复自建 Gate/Profile。


阶段 23 使用本清单，作为请求用户验收（阶段 24）之前的 Agent 自主检查。

每一项必须**实际运行**并留下证据。不得跳过。
